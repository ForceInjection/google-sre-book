    附录总览（A–G）#

    [!INFO] 出处 《SRE：Google 运维解密（第2版）》第Ⅶ部分 · 附录（p.528–539）

    一句话概括：全书各章引用的补充材料——1 个测算示例（培训 ROI）、3 份可复用的模板与实例（章程模板、生产会议纪要、gShoe 章程）、3 篇数学与方法深潜（组合 SLO、延迟告警、统计学与机器学习可观测性）。

    附录一览#

    附录 内容一句话 适用场景 链接
    A 培训投入的 ROI 计算 用"自生自灭 vs 有培训"的假设场景，把培训价值折算成 67 周 + 10000 美元 向管理层争取培训预算、评估团队投资 附录A
    B SRE 团队章程模板 元数据 + 使命/职责范围/服务/成功定义/价值观的五段式章程骨架 新团队组建、职责边界不清、与利益相关方对齐 附录B
    C 生产会议纪要示例 一份完整的生产健康会议纪要：事故、告警、琐事、SLO 指标、资源与待办 建立或校准自己团队的生产会议纪要格式 附录C
    D gShoe SRE 章程示例 按附录B模板写就的虚构团队章程全文，含 6 条可度量的成功标准 填写附录B模板前参考的成品范例 附录D
    E 组合 SLO 的数学原理 串行依赖"成功率相乘"、并行对冲"失败率相乘"的组合可用性计算 评估下游依赖对本服务 SLO 上限的影响 附录E
    F 延迟告警的数学原理 工作负载聚类 + 正态基线 + z 分数，检测全服务范围性能退化 设计低噪声、流量感知的延迟退化告警 附录F
    G 现代可观测性：统计学与机器学习 错误率的二项分布/威尔逊区间、周期性指标的 ML 预测、告警后分析 用自适应告警替代静态阈值的进阶路线 附录G

    阅读建议#

    • A–D 是工具型内容，短平快，可直接拿来用；E–G 是数学型内容，按需深入。
    • B 与 D 配套使用：先看 D 的成品找感觉，再套 B 的骨架写自己团队的章程。
    • E/F/G 分别是第8章（SLO 与 SLI）与第9章（告警策略）的进阶数学，G 还延伸到第10章的排查实践。
    • 三篇深潜的共同主题：用统计模型理解"正常"，才能精准识别"异常"——这也是第2版把可观测性从静态阈值升级为自适应告警的技术脉络。

    相关章节#

    • SLO 与 SLI 的定义 → 第8章
    • 告警策略 → 第9章

    使用方式#

    • 附录不是"看完就算"的阅读材料：B/D 是拿来抄的模板，C 是照着开会的样例，A 是拿去填数字的算式。
    • E/F/G 不需要一次性读完——在做 SLO 评审、设计延迟告警、评估自适应监控时分别回来查即可。
