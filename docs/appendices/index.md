# 附录总览（A–G）

> [!INFO] 出处
> 《SRE：Google 运维解密（第2版）》第Ⅶ部分 · 附录（p.528–539）

**一句话概括**：全书各章引用的补充材料——1 个测算示例（培训 ROI）、3 份可复用的模板与实例（章程模板、生产会议纪要、gShoe 章程）、3 篇数学与方法深潜（组合 SLO、延迟告警、统计学与机器学习可观测性）。

## 附录一览

| 附录 | 内容一句话 | 适用场景 | 链接 |
|---|---|---|---|

## 阅读建议

- A–D 是工具型内容，短平快，可直接拿来用；E–G 是数学型内容，按需深入。
- B 与 D 配套使用：先看 D 的成品找感觉，再套 B 的骨架写自己团队的章程。
- E/F/G 分别是第8章（SLO 与 SLI）与第9章（告警策略）的进阶数学，G 还延伸到第10章的排查实践。
- 三篇深潜的共同主题：**用统计模型理解"正常"，才能精准识别"异常"**——这也是第2版把可观测性从静态阈值升级为自适应告警的技术脉络。
